Download the xpi file and install the extension in the Firefox Browser.
Click on the extension and enter the amateur radio call sign you wish to monitor. Click "Save and Continue." 
The call sign will now be monitored in the background. Optionally, you can enable automatic logging of the last 15 minutes of activity to a CSV file;
this file will be saved in your "Downloads" folder. If the monitored call sign becomes active on the RBN (Reverse Beacon Network), an automatic notification will be triggered. The notification includes the skimmer, mode, frequency, and date/time.
Clicking on the notification will immediately open the RBN webpage for that specific call sign.

This extension currently only works with Firefox on standard PCs and laptops. A version for Firefox on Android is in development.
